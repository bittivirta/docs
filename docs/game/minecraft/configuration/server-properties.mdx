# server.properties -asetustiedosto

Tässä artikkelissa ohjeistetaan palvelimen asetuksien muuttamista.
Asetustiedoston löydät Gamepanelissa, kun navigoit: Palvelimesi » Files »
server.properties

:::info Huomaa!
Yksityisellä serverillä on suositeltavaa pitää [pääsylista](./whitelist) käytössä (<code>white-list=true</code>). Tällöin palvelimelle pääsee vain pelaajat, jotka ovat listalla.
:::

## Asetuksen selitykset:

Taulukossa on listattuna kaikki Minecraft-palvelimen asetustiedoston, <code>server.properties</code> asetukset ja niiden kuvaukset. Taulukon komennot ja <code>server.properties</code>-tiedosto on haettu Minecraftin versiosta 1.21.9.

Tiedoston asetukset ovat muotoa <code>nimi=arvo</code>. <br />
Esimerkiksi:
- Asetuksessa: <code>level-name=world</code> on <code>level-name</code> merkkijono-tyyppinen asetus, mikä saa syötteekseen merkkijonon: <code>world</code>
- Asetuksessa: <code>max-players=20</code> on <code>max-players</code> numeroarvo tyyppinen asetus, mikä ottaa vastaan kokonaisluvun tai murtoluvun joissakin tapauksissa. Murtoluvun desimaalierotin on piste.
- Asetuksessa: <code>enable-query=true</code> on <code>enable-query</code> totuusarvo, joka on <code>true</code> (totta/kyllä) tai <code>false</code> (taru/ei).

## Oletusasetustiedosto

Palvelimen IP-osoite ja portti vaihtelee oletusasetuksissa. Voit jättää
asetuksen halutessasi tyhjäksi, tai joksikin muuksi arvoksi, sillä siihen
korjataan aina palvelimesi osoite ja portti palvelimen käynnistyessä.

```properties
#Minecraft server properties
#[Generation date and time]
accepts-transfers=false
```
