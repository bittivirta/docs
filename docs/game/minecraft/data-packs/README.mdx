# Data Paketit

Palvelimella data paketit toimivat samankaltaisesti, kuin pluginit. Niiden tarkoituksena on muokata minecraft palvelimesi toimintaa.
Data paketit eivät varsinaisesti muuta itse pelistä mitään, sillä toisinkuin modit ne toimivat <code>/function</code> -komennolla. Data paketteja voisi verrata komentokuutioihin.
Data paketit ovat .zip-tiedostoja, mitkä sijaitsevat <code>/*Maailman-Nimi*/datapacks</code> -kansiossa palvelimella. Ne joudutaan lisäämään jokaiselle maailmalle erikseen.
