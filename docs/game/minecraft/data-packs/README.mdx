# Datapaketit

Palvelimella datapaketit toimivat samankaltaisesti, kuin pluginit. Niiden tarkoituksena on muokata minecraft palvelimesi toimintaa.
Datapaketit eivät varsinaisesti muuta itse pelistä mitään, sillä toisinkuin modit ne toimivat <code>/function</code> -komennolla. Datapaketteja voisi verrata komentokuutioihin.
Datapaketit ovat .zip-tiedostoja, mitkä sijaitsevat <code>/*Maailman-Nimi*/datapacks</code> -kansiossa palvelimella. Ne joudutaan lisäämään jokaiselle maailmalle erikseen.
