# Asentaminen

Datapaketteja voi ladata esimerkiksi sivustolta: [Modrinth](https://modrinth.com/discover/datapacks)

Datapaketit asennetaan erikseen jokaiselle Palvelimen maailmalle.
Ne sijaitsevat kansiossa <code>/*maailmanNimi*/datapacks</code>. <br /> Esimerkiksi oletus maailman nimellä <code>world</code> ne sijaitsevat kansiossa: <code>world/datapacks</code>.

:::warning Huomaa!
Datapaketit ladattaessa on hyvä varmistaa, että se on oikealle versiolle. <br />
Lisäksi esimerkiksi modrinth-sivustolla on samalla sivulla lataus useamman alustan tiedostoon, kuten: <br /> "Forge/Fabric" (Modit),  "Paper/Spigot/Bukkit" (Pluginit) ja "Data Pack" (Datapaketit). <br />
Väärän alustan/version tiedoston lataaminen yleensä aiheuttaa virheen palvelimessa.
:::
<br />

Suurin osa Datapaketeista vaativat ainoastaan sen asettamisen maailman datapaketit kansioon toimiakseen:
1. Lataa datapaketti zip-tiedostona.
2. Avaa palvelimesi tiedostonhallinta.
3. Siirry kansioon <code>/*maailmanNimi*/datapacks</code>.
4. Lähetä lataamasi datapaketti tähän kansioon.
5. Käynnistä palvelin uudelleen.

    1. Valitse tarvittaessa oikea versio ja alusta ennen lataamista.
    2. Paina "Download" eli lataus nappia.
    <Image img={require("./assets/install/1-Download.png")} />
  </Step>
  <Step>
    1. Navigoi seuraavaksi tiesi palvelimesi tiedostoihin. (Osoite: [https://gamepanel.fi](https://gamepanel.fi) )
    2. Valitse "world" kansio. Kansio voi olla eri nimellä riippuen, minkä maailman nimen olet valinnut <code>server.properties</code> -tiedostossa.
    <Image img={require("./assets/install/2-ChooseWorld.png")} />
  </Step>
  <Step>
    1. Valitse "datapacks" kansio.
    <Image img={require("./assets/install/3-ChooseDatapacks.png")} />
  </Step>
  <Step>
    1. Paina "Upload" eli tiedoston lähetys nappia.
    <Image img={require("./assets/install/4-Upload.png")} />
  </Step>
  <Step>
    1. Valitse ladattu tiedosto. (Löytyy oletuksena "Ladatut tiedostot"-kansiosta.)
    2. Varmista, että oikea tiedosto on valittu.
    3. Valitse "avaa" eli viimeistele tiedoston valinta.
    <Image img={require("./assets/install/5-ChooseFile.png")} />
  </Step>
  <Step>

    2. Varmistathan vielä oikean tiedostopolun. Eli tässä tapauksessa <code>home/container/world/datapacks</code>. Maailman nimi: <code>world</code> voi olla eri, jos olet vaihtanut oletus maailman nimeä palvelimessa.

  <Step>
